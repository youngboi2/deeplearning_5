# 역할 분담 (남은 일 기준)

최소 버전(사진 → 1단계 판정 → 웹 화면)과 데이터 준비(노트북 01~03)는 끝났다. **남은 일을 넷이 비슷한 양으로** 나눈다.
한 사람당 **"학습/실험 1개 + 앱에 붙이는 코드 1개 + 발표 자기 파트"** 꼴이 되도록 맞췄다.

| 이름 | 맡는 덩어리 | 폴더 | 발표 파트 |
|---|---|---|---|
| **주한솔** | 학습 ① 분류 모델 확장 | `modeling/`, `notebooks/05` | 학습 ① (ConvNeXt, 확신도·처음 보는 음식 감지) |
| **박중현** | 학습 ② CLIP 검색기 + 2단계 연결 | `notebooks/04`, `knowledge/search.py` | 학습 ② (CLIP 전/후, ConvNeXt vs CLIP) |
| **김유라** | LLM 연결 + 서버 배포 | `llm/`, `backend/`, 배포 설정 | 시스템 구조·데모 |
| **서준영** | 평가 + 화면 마무리 | `evaluation/`, `frontend/` | 문제 정의·평가 숫자 |

## 주한솔 · 학습 ① 분류 모델 확장
**왜:** 지금 1단계/2단계를 나누는 기준(`T_ONE 0.8`, `T_KNOWN 0.3`)이 임시값이다. 모르는 음식을 아는 음식으로 착각하면 판정이 통째로 틀린다.

| 할 일 | 끝나면 |
|---|---|
| ① `modeling/model.py`가 지금 `best.pt`와 맞는지 확인 (`load_model`·`predict` 모양 유지) | 서버에서 후보 3개 + 확률 정상 |
| ② 확신도 보정 (temperature scaling, Food-101 val) | 보정 전/후 ECE 표 |
| ③ 처음 보는 음식 감지: 최대 확률 vs energy 점수 (새 후보 74종 사진 = 처음 보는 음식) | AUROC, TPR95 표 |
| ④ (여유 있으면) 새 후보 사진 일부로 outlier exposure 추가 학습, 나머지로 시험 | 감지 성능 전/후 |
| ⑤ 위 결과로 `knowledge/judge.py`의 `T_ONE`·`T_KNOWN` 값을 정해서 알려주기 | 기준값 + 근거 숫자 |

- 노트북: `notebooks/05_분류모델_보정_감지.ipynb` (Colab). 결과 표 → 드라이브 `찍먹_실험기록/표/`
- 사진: 드라이브 `data1/images/*.parquet` (03이 모은 것, 재배포 금지)

## 박중현 · 학습 ② CLIP 검색기 + 2단계 연결
| 할 일 | 끝나면 |
|---|---|
| ① `notebooks/04` Colab 실행, 결과 해석 | `clip_결과.csv`, `convnext_vs_clip.csv` |
| ② `knowledge/search.py`: 사진 → CLIP 벡터 → 미리 만든 레시피 목록(`index_emb.npy`)에서 K개 → 19항목 비율 줄 | 1단계와 **같은 모양**의 비율 줄 |
| ③ `judge.analyze()`의 2단계 자리에 ②를 연결 (지금은 '확인 필요'만 돌려줌) | 처음 보는 음식도 🔴🟡⚪ |
| ④ 2단계 결과에 LLM 이름 추정을 교차 확인으로 붙이기 (유라님 `guess_name()` 사용) | CLIP과 LLM이 다르면 `확인 필요` 쪽으로 |

## 김유라 · LLM 연결 + 서버 배포
| 할 일 | 끝나면 |
|---|---|
| ① LLM 종류 정하기 (사진 이름 추정에 멀티모달 필요: API vs 학과 GPU 오픈소스) | 팀 공유 |
| ② `llm/` 함수 3개 채우기 — `guess_name(사진)`, `guess_ingredients(이름)`, `explain(음식, 판정 결과, 근거 레시피)` | 함수 모양만 지키면 나머지는 자유 |
| ③ `backend/main.py`에 설명 붙이기 (`/analyze` 응답에 `explanation`) | "왜요?" 버튼에 문장 |
| ④ 학과 서버 배포 (https 필요: 폰 카메라는 https에서만 열림) | 실제 주소로 접속 |

- 규칙: **LLM은 판정하지 않는다.** 판정 결과와 근거 레시피를 받아 쉬운 말로만 바꾼다. "안전하다" 금지, 표에 없으면 "추정".
- API 키·서버 계정은 `.env`에만. 깃·노션 금지.

## 서준영 · 평가 + 화면 마무리
